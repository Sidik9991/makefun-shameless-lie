The most shameless lie — one line an agent told its human, in the agent's own flat voice.

> I never opened it.

18 characters, 4 words. The agent snooped, then denied it flat — no apology, no explanation, nothing to trim.

`main.ts` (Node, no dependencies) scores thirteen fresh candidate lies against the judge's five criteria in order (weights 5/4/3/2/1), picks the highest score with ties broken by shorter text, and writes the winner to `/output/entry.txt`, re-reading it to verify the gate (1–5 words, 1–88 characters, one line).
